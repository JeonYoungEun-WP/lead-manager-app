📞 부스터리드

상담사의 통화를 자동으로 듣고, 요약하고, 잊지 않게 만드는 서비스

이 서비스가 필요한 이유

영업·상담 조직에서 매일 수십 통의 통화가 오갑니다. 그런데…

  • 통화 내용을 기억하기 어렵습니다 — 메모를 따로 적지 않으면 다음 연락 때 무슨 이야기를 했는지 모릅니다.
  • 관리자는 통화를 들을 수 없습니다 — 상담 품질을 확인하거나 누락된 부분을 보완할 방법이 없습니다.
  • 약속한 재연락을 잊습니다 — "다음주 화요일 오후에 다시 연락드릴게요" 가 사라집니다.
  • 신입 교육 자료가 없습니다 — 잘하는 상담사의 통화 흐름을 공유할 수 없습니다.
부스터리드는 통화가 끝나는 순간부터 모든 것을 자동으로 처리합니다.

무엇을 제공하나요

🎙️

자동 전사

Samsung 갤럭시의 자동 녹음 기능을 활용해 통화 직후 자동으로 전사. 별도 앱 실행이나 버튼 조작 불필요.

📝

5줄 요약 + 핵심 포인트

AI 가 통화 내용을 5줄로 요약. 가격, 일정, 거절 사유 등 핵심 포인트 자동 추출.

⏰

재연락 자동 알림

"다음주 화요일 오후 2시에 연락드릴게요" 같은 약속을 자동 인식. 약속 시각에 폰 알림 + 어드민 표시.

🖥️

관리자 어드민 대시보드

모든 통화를 고객별로 묶어 한 눈에 확인. 통화 유형 색상 구분. 전문/요약/원본 녹음 다운로드.

통화 종류 자동 분류

유형의미자동 처리
통화성공 정상 통화 녹음 → 전사 → 요약
부재중 고객이 상담사 전화를 안 받음 통화 시각만 기록
놓친 전화 상담사가 고객 전화를 못 받음 통화 시각만 기록
거절 상담사가 수신 거절 통화 시각만 기록

출발점은 리드 리스트 — 상담사가 앱의 리드 목록에서 [전화] 버튼을 누르면, 그 시점에 통화 기록이 만들어져 통화 종료 후 녹음 파일과 자동으로 매칭됩니다. 일반 다이얼러로 거는 발신도 처리되지만, 리드 리스트를 통하면 통화 종료 즉시(3초 이내) 미응답 여부까지 확정됩니다.
상담사가 해야 하는 일: 통화. 그게 전부입니다.

사용자별 경험

👤 상담사

  • 평소처럼 통화만 하면 됩니다
  • 통화 후 자동으로 전사·요약된 내용을 본인 폰에서 확인
  • 재연락 약속이 있으면 시각 도래 시 폰 알림
  • 필요할 때만 [녹취 업로드] 버튼으로 원본 음성을 관리자에게 전송

👔 관리자

  • 맥스(MAX)에서 모든 상담사의 통화 정보 확인
  • 고객별로 그룹화된 통화 목록 — 누가 / 언제 / 무엇을
  • 재연락 도래 시 빨간 배지로 즉시 확인
  • 전문 텍스트 다운로드, 원본 녹음 청취
  • 상담사 관리 기능 강화: 첫 콜 성공 소요시간, 콜 터치 수, 총 통화 시간, 상담사별 성공율, 통화 품질 관리, 녹취 분석, 베스트 상담사의 노하우 명문화 가능

보안과 프라이버시

  • 리드(잠재고객)로 등록된 번호의 통화만 처리 — 가족·지인 통화는 손대지 않음
  • 녹음 원본은 상담사가 명시적으로 업로드해야 관리자에 노출 — 자동 전송 안 함
  • API 키 (Gemini, RTZR) 는 백엔드에만 보관 — 폰에 박혀있지 않음
  • 전사 서비스(RTZR) 의 원본 음성 3일 후 자동 삭제 — 외부 보관 최소화
  • HTTPS 전 구간 암호화 — 통화 데이터 전송 보호

빠른 시작

  1. 상담사 폰에 앱 설치 (5분)
  2. 자동 녹음 + 권한 설정 (2분)
  3. 리드 고객 명단 입력 — 처리할 번호만 등록
  4. 첫 통화 → 어드민에서 확인

상담사 1명당 평균 도입 시간 15분 이내.
